# 日別収支カレンダー

毎日の支出を記録し、サブスク・固定費（家賃・通信費・動画配信サービス等）を日割りして、
「収入（日割り）− 支出」の差分を日別に確認できる家計簿PWAです。
claude.ai などの外部サービスに依存せず、GitHub Pages でホスティングして動作します。

**アプリURL**: https://issan9411-tech.github.io/daily-budget-calendar/

## 機能

- **記録タブ（ホーム画面）**: 今日あと使える金額を円形ゲージで表示し、金額入力＋カテゴリのタップ選択ですばやく支出を記録
  - **よく使う支出のテンプレート**（ワンタップで記録。「テンプレに保存」で登録）
  - **臨時収入の記録**（支出／臨時収入を切り替え。ボーナスやフリマ売上をその日の収入に加算）
  - **支出の編集**（記録画面・日別明細の「編集」から金額・カテゴリ・日付・メモを修正）
- **カテゴリ別の予算**（任意）: 設定すると記録画面に「今月あといくら」、サマリーに消化状況バーを表示
- 支出の記録（日付・金額・カテゴリ・メモ）と日別の収支一覧（**週計行**つき）
- **月別の収支グラフ**（6か月の実績比較）
- 固定費・サブスクの登録（**月払い／年払い**を選択可能。年払いは年額÷12で月額換算）
  - 月額は「月額 ÷ その月の日数」で日割りされ、毎日の支出に自動計上
  - 開始月・終了月の設定、編集・削除に対応
- 月収（手取り）の日割りとの差分・累計差分の表示
  - **月収は期間ごとに登録可能**（昇給・転職時は開始月〜終了月で切り替え。旧データは自動移行）
- **記録の開始日**を設定でき、それより前の期間は収入・固定費・累計収支に含めない
- 収支は**今日までの実績**で計算（未来の日の収入・固定費は計上しない）。月末までの計画は「月末見込み」タイルで別途表示
- 月間サマリー（カテゴリ別内訳）、グラフ（日別支出・累計収支）
- CSV出力（日別収支・支出明細）、JSONバックアップ／復元
- **端末間同期（GitHub Gist）** — 下記参照

## 端末間の同期

データは通常ブラウザ内（localStorage）に保存されますが、GitHubの**非公開Gist**を使った同期を有効にすると、
スマホ・PCなど複数の端末で同じデータを共有できます。

1. [トークン作成ページ](https://github.com/settings/tokens/new?scopes=gist&description=kakeibo-sync)（gist権限のみのクラシックトークン）でトークンを発行
2. アプリの「設定 → 端末間の同期」にトークンを貼り付けて「同期を有効にする」
3. 他の端末でも同じトークンを貼り付けると、同じGistに自動接続されます

- トークンは各端末のブラウザ内にのみ保存され、Gistの読み書き以外には使えません
- 同期のタイミング：起動時・アプリに戻ったとき・データ変更時（自動）。「今すぐ同期」ボタンもあります
- 競合時は更新日時が新しい方を採用します

## 記録リマインダー（プッシュ通知）

指定時刻に「その日の支出がまだ記録されていない」場合だけ、登録した端末に通知を送ります。
送信はこのリポジトリの GitHub Actions（毎時実行）が行うため、サーバーは不要です。

**初回設定（リポジトリ側・1回だけ）**

1. リポジトリの Settings → Secrets and variables → Actions → New repository secret で次の3つを登録
   - `GIST_TOKEN` — 同期に使っているgist権限のトークン（同じものでOK）
   - `VAPID_PUBLIC_KEY` — アプリに埋め込まれている公開鍵（`index.html` の `VAPID_PUBLIC` と同じ値）
   - `VAPID_PRIVATE_KEY` — 対になる秘密鍵
2. 鍵を作り直したい場合は `npx web-push generate-vapid-keys` で生成し、公開鍵を `index.html` の `VAPID_PUBLIC` に反映してください

**各端末での設定**

1. アプリの「設定 → 記録リマインダー」で時刻を選び「この端末で通知を有効にする」
2. iPhoneは「ホーム画面に追加」したアプリから開いて設定してください（iOS 16.4以降）
3. 「テスト通知」で表示を確認できます

補足: GitHub Actions のスケジュール実行は数分〜数十分遅れることがあります。また、リポジトリに
60日間pushが無いとスケジュールが自動停止されるため、その場合は Actions タブから再有効化してください。

## iPhone / Android でアプリとして使う

1. ブラウザ（iPhoneはSafari）でアプリURLを開く
2. 共有メニューから「ホーム画面に追加」
3. ホーム画面のアイコンから、独立したアプリとして起動できます（オフラインでも閲覧・記録可能。同期は通信回復時）
